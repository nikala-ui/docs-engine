---
title: Search
description: Configure the documentation search trigger and provider.
order: 5
---

Local search is enabled by default and is the built-in provider:

```ts
export default {
  search: {
    enabled: true,
    provider: "local",
  },
};
```

Set `enabled: false` to remove the search trigger and disable the default
theme's keyboard shortcut.

The default theme implements `local`, which searches page titles, URLs, and
descriptions. If `pagefind`, `orama`, or `algolia` is selected before a
corresponding integration is installed, the engine safely falls back to the
local implementation while preserving the requested provider in the resolved
configuration.
