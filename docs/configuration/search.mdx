---
title: Search
description: Configure the documentation search trigger and provider.
order: 5
---

Local search is enabled by default and is the built-in provider:

```ts
export default {
  search: {
    enabled: true,
    provider: "local",
  },
};
```

Set `enabled: false` to remove the search trigger and disable the default
theme's keyboard shortcut.

The default theme implements `local`, which searches page titles, URLs, and
descriptions. External integrations provide a `SearchAdapter` through the
configuration instead of requiring provider-specific code in Folio:

```ts
import type { SearchAdapter } from "@nikala-ui/folio";

const adapter: SearchAdapter = {
  name: "my-search",
  async search({ query, pages }) {
    return pages.filter((page) => page.title.toLowerCase().includes(query.toLowerCase()));
  },
};

export default {
  search: {
    provider: adapter.name,
    adapter,
  },
};
```

If a provider name is configured without an adapter, the engine safely falls
back to the built-in local implementation.
